# APP — Profil Dusun Pulesari

Paket website statis berbasis HTML, CSS, dan JavaScript inline pada setiap halaman. Struktur file dibuat langsung pada root agar mudah diunggah sebagai GitHub Pages dan disematkan di Google Sites melalui URL publik.

## Interaksi prototipe
- Navigasi halaman dan menu ponsel.
- Pencarian/filter sisi browser pada beberapa katalog.
- Interaksi kalender dan filter kategori/lokasi.
- Preferensi tampilan halaman Pengaturan disimpan di localStorage browser pengguna.
- Peta eksternal ditampilkan melalui tautan/embed penyedia.

## Belum tersedia
Tidak ada backend/database bersama atau akun admin asli. Formulir tidak mengirim pengajuan, status layanan tidak tersimpan, dan perubahan pada localStorage tidak tersinkron antarpengguna. Untuk penggunaan administratif nyata, hubungkan formulir, dokumen, dan data ke backend dengan autentikasi dan kontrol akses yang sesuai.
