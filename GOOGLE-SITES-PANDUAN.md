# Panduan GitHub Pages dan Google Sites

## A. Publikasikan website
1. Ekstrak ZIP final.
2. Unggah seluruh file ke root repository GitHub; `index.html` harus langsung berada di root.
3. Aktifkan GitHub Pages dari branch utama dan folder root (`/`) pada Settings → Pages.
4. Buka URL Pages yang muncul dan uji semua menu, gambar, peta, serta tampilan desktop dan ponsel.

## B. Sematkan website di Google Sites
1. Buka Google Sites yang akan digunakan.
2. Pada menu **Sisipkan**, pilih **Sematkan**.
3. Pilih tab **URL**, masukkan URL GitHub Pages, lalu pilih sisipkan.
4. Sesuaikan lebar dan tinggi bingkai agar isi dashboard tidak terpotong.
5. Pratinjau dalam desktop dan ponsel, lalu publikasikan Google Sites.

Google Sites tidak menjalankan file ZIP secara langsung. HTML harus di-host di URL publik terlebih dahulu, misalnya melalui GitHub Pages. Beberapa fitur peta atau konten eksternal memerlukan koneksi internet dan dapat mengikuti kebijakan embed penyedia.

## Batasan
Website saat ini merupakan prototipe statis. GitHub Pages tidak menyediakan backend/database. Login admin, penyimpanan data, pengiriman formulir, manajemen dokumen, dan layanan administrasi nyata harus dihubungkan ke layanan backend yang aman.
