# Style Guide

- Hijau hutan: `#052F23` / `#073B2B` untuk sidebar dan identitas.
- Hijau aksi: `#08754D` untuk tombol utama.
- Emas: `#EFA128` untuk aksen banner dan status aktif.
- Biru informasi: `#2458A7` untuk ikon dan link.
- Latar: `#F3F5F9`; kartu: `#FFFFFF`; garis: `#E5EAF1`.
- Layout acuan: 1536 × 1024 px. Sidebar ±243 px, topbar 56 px, hero 244 px.
- Judul: Georgia/serif; antarmuka: font sistem sans-serif.
- Radius kartu 10–12 px; jarak komponen 10–13 px.
- Responsive breakpoints: 1390 px, 1050 px, dan 700 px.
